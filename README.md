## 📖 Sobre el Proyecto

Este repositorio contiene las actividades, prácticas y proyectos desarrollados en la asignatura **Desarrollo Web**.

El objetivo principal es aplicar conocimientos en:

- 🏗️ Estructura y maquetación con **HTML5**
- 🎨 Diseño y estilos con **CSS3**
- ⚡ Desarrollo y tipado estático con **JavaScript & TypeScript**
- 🛠️ Desarrollo de API REST con **NestJS**
- 🛢️ Gestión de bases de datos con **PostgreSQL**
- 🐳 Contenerización y despliegue con **Docker**
- 🔄 Control de versiones y trabajo colaborativo con **Git & GitHub**

---

## 🎯 Objetivos Académicos

- Comprender la estructura del desarrollo web moderno.
- Implementar buenas prácticas de diseño y organización del código.
- Desarrollar proyectos funcionales y responsivos.
- Trabajar colaborativamente en equipo.
